## Measurement and terminal rule

Compare operator, predicate count and the set of unique location assignments
against the constructed control. Inspect predicate roles/content separately.
Duplicate assignment count cannot establish ambiguity. These measurements
qualify neither the model generally nor the public corpus.

Allowed dispositions: SUPPORTED_BOUNDED_WITNESS_DIAGNOSTIC,
FALSIFIED_LOCAL_COLD_WITNESS_ORACLE, FAILED_APPARATUS.
Any semantic mismatch prevents support. A runtime failure is not a model semantic
error. Class labels inferred from witnesses are evaluation observations only;
they are never runtime ClaimGate authority.

If the witness channel also fails, the local raw-model oracle architecture is
falsified across label and witness channels. End this bounded oracle branch
negative, with a smaller successor hypothesis: externally reviewed root-scope
and obligation certificates plus qualified independent checks. More formatting

reasoning settings, parser lanes and human review remain alternate explanations,

its own authority/assurance protocol before decisive S1.

If witnesses succeed, preserve the scalar failure and preregister a fresh public
