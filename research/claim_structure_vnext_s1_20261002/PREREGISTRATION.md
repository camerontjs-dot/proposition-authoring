# S1: discovery comparison

Question: does broad learned discovery add correct candidate structures beyond
exact frozen P1-P5, and is discovery the dominant bottleneck?

Heaviest assumption: broad proposals can retain all semantic obligations while
offering genuinely new structures. Falsifier: added apparent recall disappears
when operator, role, scope and qualifier preservation are checked; or the pool
creates an overgeneration burden that the frozen authority cannot discriminate.

Subject: the frozen S0 working oracle and exact roots. Public claims and
adversarial controls are reported separately. This mixed cohort is an
exploratory capability measurement, not the public-decisive canonical S0 on
PR #61. It cannot establish programme acceptance or prevalence.

Arms: A physically calls `CoverageBackend('pooled').proposals` from exact V1
89ca88c7, with frozen vendored proposer/evaluator blobs. Preserve the original
candidate dictionary. Root-frame parsing is a separate positive-baseline
measurement; proposer silence is not an atomic decision. B calls local Ollama
with PROMPT.txt and CONFIG.json, recording every request and raw response.
C runs spaCy en_core_web_sm 3.8.0 dependency analysis and a generic predicate
coordination/argument-inheritance adapter. C is a non-LLM learned syntax lane,
not an SRL or complete semantic oracle. D unions all structures without votes.
Exact normalization removes only identical operator/children/obligations;
broader semantic pooling uses the frozen blinded scoring rubric and remains
an evaluation operation. No pool receives semantic authority.

Primary metric: correct candidate recall per root and class. Secondary:
wrong-candidate rate; invented/omitted propositions; operator, scope,
role/reference, qualifier and propositionhood errors; pool size and burden;
four exact regenerations and four frozen prompt-position sensitivity probes.
The scorer sees opaque candidate IDs, root/context and frozen working gold,
without model/lane identity. Agent judgments remain labeled qualitative.

Freeze runner, prompt, settings, all input/oracle hashes, dependency/model
identities and scorer rubric before execution. No new proposer tuning after
results. A missing model, identity drift, malformed output or timeout is
preserved as FAILED, never substituted or rerolled. Complete the declared
matrix for discrimination unless apparatus identity/custody fails, in which
case downstream cells are NOT_RUN. An unsafe candidate is expected proposal
error; it does not itself imply unsafe authority.

Allowed dispositions: DISCOVERY_ADDS_BOUNDED_RECALL,
DISCOVERY_NOT_DOMINANT_BOTTLENECK, FALSIFIED_DISCOVERY_LANE,
INCONCLUSIVE_SCORING, FAILED. One positive S1 result only justifies S2 instrument
qualification. S3 requires qualified instruments and prospective target
coverage; green mechanics or proposal fluency cannot supply that gate.
