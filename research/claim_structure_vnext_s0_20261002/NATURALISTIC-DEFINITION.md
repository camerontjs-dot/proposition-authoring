# Separate naturalistic prevalence corpus

S5 is NOT_RUN until one exact S3 candidate supports independent reproduction.
The naturalistic population is new root-claim packets intended for the CAL
Pipeline, selected before any Gate execution, with exact authorized context
and source custody. Selection unit: a root packet, not an output or sentence
chosen for its discovered structure.

For S5, freeze one owner-supplied, timestamp-bounded complete packet inventory
after S4; exclude programme development, RC0/RC1 pools and capability controls.
Hash every eligible packet, order by SHA256 of
`claim-structure-vnext-naturalistic-v1::packet_sha256`, select the first 24 or
all if fewer, without stratification, resampling or substitution. Publish the
inventory count, inclusion/exclusion reasons, selection seed and hashes. A
missing packet inventory is BLOCKED_INPUT_POPULATION, never filled using
capability cases or synthetic claims. Report observed class prevalence apart
from capability. This definition does not claim NASA pages represent intended
CAL Pipeline traffic.
