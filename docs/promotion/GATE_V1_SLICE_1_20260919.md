# ClaimGate + EvidenceGate V1 Slice 1

## Purpose

This is the smallest production-shaped Gate surface justified by the frozen V1.0.0 record and the post-release Contract A conformance falsifier.

It does one additional thing at the Gate → Contract A boundary:

> if the supplied source representation cannot be represented by released Contract A 2.0.0, stop before emitting Contract A instead of handing an invalid object downstream.

ClaimGate decomposition/classification semantics and EvidenceGate representation semantics remain the released V1.0.0 semantics.

## Behavior

### Contract-A-representable source

For source representations already inside the exact released Contract A 2.0 vocabulary:

- `text/plain; charset=utf-8`
- `text/markdown; charset=utf-8`

the slice returns the exact V1.0.0 Gate result unchanged.

### Source outside Contract A 2.0

If V1 authoring would otherwise emit Contract A and any source representation is outside that vocabulary:

- EvidenceGate still describes the actual supplied representation;
- no representation is transformed or relabeled;
- ClaimGate uses existing authoring state `FAILED`;
- reason is `CONTRACT_A_SOURCE_REPRESENTATION_UNSUPPORTED`;
- Contract A binding is absent;
- standardization receipt marks Contract A absent;
- `evidence_bundler_may_consume_contract_a=false`;
- no Contract A object is emitted.

This is a fail-closed producer-boundary correction. It is not a new claim semantic, EvidenceGate authority, or representation-conversion service.

## Operator surface

```bash
python scripts/run_gate_production_slice_v1.py \
  PACKET.json \
  --out-dir RUN_DIR/gate \
  --implementation-identity <pinned-identity>
```

A successful downstream path consumes `RUN_DIR/gate/CONTRACT-A.json`. If that file is absent, Evidence Bundler must not be invoked for that Gate run.
