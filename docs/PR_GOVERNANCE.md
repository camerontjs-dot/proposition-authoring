# Pull request evidence checklist

Every substantive Proposition Authoring pull request should state:

1. classification: Research, Research Infrastructure, Promotion, or Maintenance;
2. exact bounded claim under review;
3. base SHA and frozen promotion-critical identities;
4. preregistered positive evidence requirements;
5. hard falsifiers;
6. weak controls, mutations, metamorphic tests, and counterexamples;
7. execution or harness deviations with affected run identities;
8. evaluator independence, adjudication source, contamination controls, and assurance limits;
9. observed results separated from inference;
10. residual unknowns and explicit non-claims;
11. production impact;
12. smallest next discriminating test;
13. one terminal disposition when complete: `SUPPORTED FOR PROMOTION`, `FALSIFIED`, `INCONCLUSIVE`, or `SUPERSEDED`.

Research PRs are evidence records. A green workflow does not establish the hypothesis, and a research branch should not be merged wholesale as a production change merely because the experiment succeeded.
